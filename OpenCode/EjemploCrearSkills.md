# Ejemplo

## Skill para consultar pokeno
```
Necesito que me ayudes a crear un skill que sirva para tomar la informacion de los pokemon es cuando yo lo necesite. si menciono algo de pokenon, puedes usar esta habiliad.

La habilidad necesita ir a buscar la informacion del pokemon a esta API
https://pokeapi.co/api/v2/pokemon/ditto

tambien funciona de esta manera
https://pokeapi.co/api/v2/pokemon/1

puedo mandar el nombre o el id del pokemon, cualquier tema de conversacion sobre algun pokemon debe consultarla para poder responder de manera apropiada

ayudame a crear esta skill

```
